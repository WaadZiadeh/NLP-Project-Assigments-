# Natural Language Processing (NLP) Assignments & Project

This repository contains assignments and a project completed as part of the **Natural Language Processing (NLP)** course.

## 📚 Assignments

### Assignment 1 — Regular Expressions, Arabic Stemming & Lemmatization

This assignment focuses on:

* Using **Regular Expressions (Regex)** for text processing and pattern matching.
* Applying **Arabic stemming and lemmatization** techniques.
* Exploring basic Arabic text preprocessing.

### Assignment 2 — N-gram Language Models

This assignment focuses on:

* Building **N-gram Language Models**.
* Calculating probabilities of word sequences.
* Using previous words to predict the next word in a sequence.

### Assignment 3 — Word Embeddings: Count-Based and Prediction-Based Representations

This assignment focuses on:

* Understanding different **word representation techniques**.
* Exploring **count-based word representations**.
* Exploring **prediction-based word embeddings**.
* Comparing different approaches for representing words numerically.

## 🧠 Project — Part-of-Speech (POS) Tagging

**Part-of-Speech Tagging on the English Penn Treebank using Baseline and Neural Sequence Tagging Models**

The project focuses on automatically assigning **Part-of-Speech (POS) tags** to words in sentences from the **English Penn Treebank**.

The project includes:

* Preprocessing and preparing the Penn Treebank dataset.
* Implementing a **baseline POS tagging model**.
* Developing **neural sequence tagging models**.
* Training and evaluating the models.
* Comparing the performance of baseline and neural approaches.
